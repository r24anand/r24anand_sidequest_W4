## Description

This is a grid-based maze puzzle game. Each level is a tiled maze made up of walls and different floor paths. The player controls a blue circle that moves one tile at a time through the maze using the arrow keys or WASD.

The objective of each level is to collect all the orange circles that appear in the maze. Once all circles are collected, to go to the next level the circle has to go to the green exit tile. Stepping onto that tile completes the level. There are two levels. Completing the first level leads to the second and after finishing the second level, the game displays a win screen.
